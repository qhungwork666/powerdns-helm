PowerDNS + Poweradmin installed.

DNS LoadBalancer:
  kubectl -n {{ .Release.Namespace }} get svc {{ include "powerdns-poweradmin.fullname" . }}-pdns

PowerDNS API:
  kubectl -n {{ .Release.Namespace }} get svc {{ include "powerdns-poweradmin.fullname" . }}-pdns-api

PostgreSQL:
  kubectl -n {{ .Release.Namespace }} get cluster {{ include "powerdns-poweradmin.fullname" . }}-postgres

Gateway API route:
  kubectl -n {{ .Release.Namespace }} get httproute {{ include "powerdns-poweradmin.fullname" . }}

Important:
  * The Gateway itself is expected to be platform-managed by Envoy Gateway.
  * The PowerDNS API is intentionally ClusterIP-only.
  * PowerDNS requires both TCP/53 and UDP/53.
